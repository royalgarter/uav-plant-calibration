UAV Phenomics Image Processing

About the processing pipeline

Pipeline Overview

This software processes multispectral UAV imagery (DJI Phantom 4 Multispectral, P4M) through a four-stage pipeline: parsing & dewarping, coarse-to-fine image alignment, radiometric calibration (optional), and vegetation index computation. The output is a set of co-registered, calibrated index maps together with CSV reports for quantitative analysis.

./calib <input_dir> <output_dir> [--radio] [--auto] [--optimize] [--veg-idx=ndvi,...] [--green-centroid-radius <px>] [--color-mask <h,s,v;...> --color-tol <h,s,v>] [--kmeans] [--spatial [--spatial-merge-dist <px>]] [--gentle [--gentle-radius <frac>]]

Input Data Convention

Images are grouped by a common prefix (e.g. DJI_097). The last character of the stem encodes the spectral band:

SuffixBandAlias
0RGB composite—
1Blue475 nm centre
2Green560 nm centre
3Red650 nm centre
4Red edge730 nm centre
5Near-infrared (NIR)840 nm centre

Files are parsed as TIFF (preferred, XMP embedded) or JPEG (APP1 segment scanned for XMP). Group detection uses the prefix (stem minus last character).

Preprocessing & Alignment

Metadata Parsing (XMP)

Each image contains DJI-specific XMP metadata that is extracted from the TIFF tag 700 (or from the JPEG APP1 segment when a TIFF is unavailable). Regular-expression scanning extracts:

  • DewarpData — nine intrinsic / distortion parameters (fx, fy, cx, cy, k1, k2, p1, p2, k3).
  • CalibratedOpticalCenter — the principal-point offset determined by DJI factory calibration.
  • RelativeOpticalCenter — per-image translation (Δx, Δy) relative to the group reference.
  • DewarpHMatrix — a 3×3 homography that maps the sensor coordinate system to a common mosaic frame.

Lens Dewarping

The DJI P4M has a significant fisheye lens. Using the extracted DewarpData, the image is undistorted via OpenCV’s cv::undistort with a standard Brown–Conrady distortion model. The calibrated principal point is:

cx = width / 2 − dewarp_cx
cy = height / 2 + dewarp_cy

The camera matrix K is built from (fx, fy, cx, cy) and the distortion vector D contains (k1, k2, p1, p2, k3).

Coarse Alignment (Metadata Homography)

Each image is first warped to the reference image geometry using the DJI-provided DewarpHMatrix (H). If no matrix is available, a pure translation is applied using the RelativeOpticalCenter values. This brings all bands into approximate pixel-level registration.

Fine Alignment (ECC & SIFT Fallback)

After the metadata warp, a correlation-based fine alignment is performed. The reference image and the warped target image are preprocessed by:

  1. Converting to grayscale and applying CLAHE (contrast-limited adaptive histogram equalisation, clip-limit 2.0, 8×8 tiles).
  2. Gaussian blur (5×5 kernel) to suppress sensor noise.
  3. Scharr gradient magnitude (X and Y) to produce a polarity-free structural representation.
  4. Min–max normalisation to [0, 1] for numerical stability.

The primary fine-registration method is Enhanced Correlation Coefficient (ECC) maximisation with a homography motion model (MOTION_HOMOGRAPHY). If ECC fails to converge (e.g. due to poor initial alignment or low texture), a SIFT fallback is used:

  • SIFT keypoints are detected on CLAHE-enhanced versions of both images.
  • Matches are filtered by Lowe’s ratio test (threshold 0.75).
  • A homography is estimated from the surviving matches via RANSAC.

The --optimize flag enables performance tuning: images can be downscaled (d) before ECC and the result is scaled back by adjusting homography translation and perspective components:

Hfull = S−1 · Hdown · S

Default optimisation parameters: downscale 2×, 50 iterations, ε = 10−4.

Radiometric Calibration

When --radio is enabled, raw digital numbers (DN) are converted to reflectance values using a linear model per band. A calibrated reflectance panel with four known patches (56.47%, 35.82%, 11.48%, 2.72% reflectance) is used as reference.

Board Detection

With --auto, the board is located by template matching across multiple scales (0.2–2.0×, step 0.15) and four rotations (0°, 90°, 180°, 270°). The matching score is a weighted combination of:

  • Normalised cross-correlation (TM_CCOEFF_NORMED) on raw intensity.
  • Normalised cross-correlation on the Sobel gradient magnitude (edge map).

Both channels are thresholded at zero (removing negative/inverted matches) and combined with equal weight (50/50). The best score must exceed 0.45. Once the board is found, two anchors — the 56% patch centre (p56) and the 3% patch centre (p3) — are computed relative to the template geometry, accounting for scale and rotation. The border thickness parameter T defines the inset from the template edges to the patch region.

If the board cannot be detected automatically (or --auto is not used), a manual two-click interface allows the user to pick p56 and p3 interactively.

DN Collection & Coefficient Estimation

Four anchor points are interpolated linearly between p56 and p3. At each anchor, the mean pixel value is sampled from a 5×5 box centred on the anchor:

pi = p56 + (p3 − p56) × i / 3,   i = 0, 1, 2, 3

The per-channel linear coefficients (a, b) are solved by ordinary least squares via singular value decomposition (SVD):

reflectancei = a · DNi + b,   i = 1..4

For RGB images (band 0), independent coefficients are computed for each of the three channels (R, G, B). For multispectral bands (1–5), a single coefficient pair is estimated. The reference reflectance values are loaded from an external CSV (file keyed by band name: 5 for NIR, 3 for Red, 0R/0G/0B for RGB channels, etc.).

Application & Visualisation

The linear transform is applied across the whole image with cv::convertTo. The resulting reflectance image is then contrast-stretched to [0, 255] for 8-bit visualisation. Both the raw (pre-calibration) aligned image and the radiometrically calibrated version are saved. A CSV report (radiometric_report.csv) summarises all collected DN values per band, per anchor point, along with the estimated slope and intercept.

Vegetation Indices

Twenty-seven vegetation indices are available, covering a broad spectrum of physiological and structural vegetation properties. Each index is computed as a per-pixel floating-point formula. The result is constrained to [0, 1] (negative values clamped to zero, values above 1 clamped to 1). If a required band is missing, the index is silently skipped.

Green Masking Pipeline

A vegetation mask is computed from the RGB (band 0) image and applied to all index calculations, isolating plant matter from soil and background. The mask is built in six stages:

  1. Plant index score. A custom spectral score G + R − 2B is computed, normalised to [0, 255], and thresholded via Otsu.
  2. GNDVI fusion. If NIR (band 5) is available, GNDVI is computed and thresholded with Otsu. The two binary masks are combined: mask = (index | GNDVI) & AND(index, GNDVI). A weighted score 0.6 · Index + 0.4 · GNDVI is also Otsu-thresholded and fused via OR.
  3. HSV range filter. Pixels outside H [18, 90], S [25, 255], V [30, 255] are removed to eliminate non-vegetation hues (e.g. dark soil, sky).
  4. Morphological cleanup. Median blur (3×3), morphological closing (3×3 ellipse), and dilation (3×3 ellipse, 1 iteration).
  5. Statistical outlier filtering. Connected components smaller than 15 px are discarded. An area-weighted centroid and spread standard deviation are computed; blobs farther than max(3σ, 10% image width) from the centroid are rejected. This eliminates isolated bright spots caused by specular reflections or non-plant material. The surviving contours are used to fit a convex hull (yellow), a rotated ellipse (red), and a centroid marker (blue cross) for visual verification.
  6. Spatial focus (optional). When --green-centroid-radius is set, a circular mask centred on the vegetation centroid (or the image centre as fallback) restricts analysis to a radius R. When disabled, a 5% border margin is applied to avoid edge artefacts.

Color-Spot Leaf Selection

Instead of the default green filter, you can drive segmentation from colours you pick on real leaves. In the Web UI, click Pick Color Leaves to open the input folder's images, then left-click leaf areas to capture one or more HSV spots. Each spot is expanded by a single global HSV tolerance and OR'ed into a color-mask that replaces the default saturation/chroma and RGB PlantIndex stages. The mask is combined with the Low-NDVI and Texture filters. Hue wraps correctly at the 0/180 boundary.

  • --color-mask <h,s,v;h,s,v;...> — one or more HSV spot centres (hue uses OpenCV 0–180).
  • --color-tol <h,s,v> — global per-spot HSV tolerance (defaults 15, 40, 40).

Advanced Preprocessing Options

Three optional refinement stages are available to separate genuine plant canopies from confusing background such as moss, drought-stressed leaves, or satellite blobs:

  • --kmeans — spectral K-Means clustering of the candidate mask in HSV/NDVI space. The plant cluster is kept, and a convex-hull region (expanded 1.2× about the plant centroid) bounds the final mask. When the two clusters' bounding boxes overlap (one canopy split by clustering) the hull is built over the union so nothing is amputated.
  • --spatial — spatial proximity clustering. Contours whose centroids fall within --spatial-merge-dist pixels (default 50) are merged into one cluster; stray satellite blobs are discarded.
  • --gentle — gentle/stressed-plant mode, with a soft background rejection tuned to preserve yellow/brown leaves. --gentle-radius (default 0.38) controls the anchor radial enclosure as a fraction of image width.

Output Products

For each selected vegetation index, three output files are written to <output_dir>/vegetation_index/:

  • <prefix>_<index>_raw.tif — 32-bit float GeoTIFF of the raw index values.
  • <prefix>_<index>_u8.jpg — 8-bit contrast-stretched JPEG for quick browsing.
  • <prefix>_<index>_color.jpg — Pseudocoloured JPEG using the JET colour map.
  • <prefix>_green_mask.tif — RGB composite with the green mask overlay and geometric annotations (first index only).
  • <prefix>_mask.jpg — Binary mask image.

A summary CSV (vegetation_index_report.csv) records the mean index value (over non-masked pixels) for every group and every requested index.

Web UI Tools

Image Gallery

A folder selector lets you browse Correlation Alignment, Radiometric Calibration, and Vegetation Indices output directories. Images are loaded as thumbnails; clicking one opens the full-resolution viewer with overlay controls.

Image Navigation

Inside the full-resolution viewer you can move through every image in the current folder with the left/right arrow keys or the on-screen chevron buttons. Navigation wraps around at the ends, and the anchor/overlay layer updates to match each newly selected image.

Pick Color Leaves

In the preprocessing panel, Pick Color Leaves opens the input folder's RGB images. Use the left/right arrow keys or chevron buttons to browse across images in different lighting/plant conditions, and left-click on leaf areas to capture color spots. Each spot is expanded by the global HSV tolerance into a segmentation mask that replaces the default green filter. Spots persist across image navigation; use the x on a spot to remove it or Reset to return to the default green filter.

Overlay Comparison

When a vegetation index image is opened, the anchor image (the processed RGB — band 0 — from the alignment output) is loaded as the background layer. The selected index image is overlaid on top with an adjustable opacity slider (0–100%), enabling side-by-side visual comparison between the natural-colour reference and the index heat map.

Line Profile Tool

Click two points on the overlay image to define a transect line. A floating modal draws a brightness profile along that line, plotting grayscale intensity (0–255) against distance. Hovering over the profile shows a marker on the image at the corresponding position and the exact pixel value. The profile modal can be dragged by its header and its position is persisted across sessions via localStorage.

Reports Viewer

CSV files generated in the output directory are listed in the Reports tab. Selecting a file renders it as an HTML table for quick inspection of radiometric DN values and vegetation index averages.

Log Streaming

When the PROCESS button is clicked, the backend executes the calib binary and streams its stdout line-by-line via a JSON-delimited HTTP response. The log area auto-scrolls to show the latest output, providing real-time feedback on the processing status.

CSV Report Format

Radiometric Report

radiometric_report.csv contains one row per image group. Columns:

  • Filename — the reference image filename for the group.
  • DN_B1_P1–DN_B5_P4 — DN values for each multispectral band (1–5) at each of the 4 anchor points.
  • DN_RGB_R_P1–DN_RGB_B_P4 — per-channel DN values for the RGB image (band 0).
  • Slope (a), Intercept (b) — the linear calibration coefficients (mean of RGB channels if applicable).

Vegetation Index Report

vegetation_index_report.csv contains one row per image group. Columns:

  • Group prefix — the shared prefix (e.g. DJI_097).
  • <INDEX>_Avg — one column per requested vegetation index containing the spatial mean over non-masked pixels.
